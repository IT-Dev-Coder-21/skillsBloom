# 🌱 Skills Bloom - Full Stack Mentorship Platform

## 📌 Overview

Skills Bloom is a full-stack web application that connects students with mentors for booking learning sessions, asking questions, and tracking progress.

## 🛠️ Tech Stack

- Frontend: React
- Backend: Node.js + Express
- Database: MySQL
- Styling: CSS

## 🚀 Features

- User Authentication (Student & Mentor)
- Mentor Booking System
- Student Dashboard
- Mentor Dashboard
- Session Management
