# 🌸 Skills Bloom

At Skills Bloom, we are dedicated to bridging the gap between ambitious students and experienced industry mentors. Our mission is to foster a collaborative ecosystem where technical knowledge is shared, professional growth is accelerated, and the next generation of innovators is empowered to solve real-world challenges.

 🚀 Live Demo
Check out the live application here: https://skills-bloom.vercel.app/

 🛠 Tech Stack
Skills Bloom is a full-stack web application built with the following technologies:

*   Frontend: React,
*   Backend: Node.js, Express
*   Database: MySQL
*   Deployment: Vercel (Frontend), Render (Backend)

📋 Features
*   Mentor Discovery: Easily browse and view professional profiles.
*   Seamless Booking: Students can schedule mentorship sessions directly through the dashboard.
*   Interactive Dashboard: Personalized views for both mentors and students to manage active sessions.
*   Responsive Design: Fully optimized for both desktop and mobile devices.
